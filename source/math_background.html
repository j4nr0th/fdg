Mathematical Background#

This page collects the mathematical conventions used throughout fdg. Every other page in this documentation refers back to it. The conventions match the implementation exactly: the formulas below are the ones the C core and the Python bindings evaluate, including the sign conventions.

Reference Domain#

All one-dimensional bases and quadrature rules live on the reference interval

\[\xi \in [-1, +1] .\]

An \(N\)-dimensional reference domain is the tensor product \([-1, +1]^N\); a point in it is written

\[\begin{split}\vec{\xi} = \begin{bmatrix} \xi_1 \\ \vdots \\ \xi_N \end{bmatrix}, \qquad \xi_i \in [-1, +1] .\end{split}\]

A deformed element is the image of this reference domain under a space mapping

\[F : [-1, +1]^N \to \mathbb{R}^M, \qquad \vec{x} = F(\vec{\xi}),\]

with \(M \ge N\). The reference coordinates are always denoted by \(\vec{\xi}\) and the physical coordinates by \(\vec{x}\).

Differential Forms#

A differential :math:`k`-form on an \(N\)-dimensional domain is a smooth antisymmetric multilinear map that assigns to \(k\) tangent vectors a scalar. In a coordinate basis it is written as a sum over wedge monomials of coordinate differentials,

\[\omega = \sum_{i_1 < \dots < i_k} \omega_{i_1 \dots i_k} \,\mathrm{d} x_{i_1} \wedge \dots \wedge \mathrm{d} x_{i_k},\]

where the sum runs over the \(\binom{N}{k}\) strictly increasing index sets \(\{i_1, \dots, i_k\} \subset \{1, \dots, N\}\). The scalar functions \(\omega_{i_1 \dots i_k}\) are the components of the form. A \(0\)-form is just a scalar function.

fdg stores a \(k\)-form as a collection of components. The components are indexed lexicographically by their ascending axis sets: \(\{1, 2\}\) before \(\{1, 3\}\) before \(\{2, 3\}\), and so on. The number of components is the binomial coefficient \(\binom{N}{k}\), which is what KFormSpecs.component_count returns.

Each component is expanded in its own tensor-product function space. If the base (0-form) space has polynomial order \(p_i\) in dimension \(i\), the space of the component with active axes \(\{i_1, \dots, i_k\}\) has order \(p_i\) on the inactive axes and order \(p_i - 1\) on the active (wedged) axes. The number of degrees of freedom of one component is therefore

\[\begin{split}\prod_{i = 1}^{N} \begin{cases} p_i, & i \in \{i_1, \dots, i_k\} \\ p_i + 1, & i \notin \{i_1, \dots, i_k\} \end{cases}\end{split}\]

One degree of freedom less per active axis: the antisymmetry of the wedge product makes the component vanish where two active coordinates coincide, so no nodal values are needed on those planes.

The Wedge Product#

The wedge product of two forms is associative, bilinear and antisymmetric,

\[\mathrm{d} x_i \wedge \mathrm{d} x_j = - \mathrm{d} x_j \wedge \mathrm{d} x_i, \qquad \mathrm{d} x_i \wedge \mathrm{d} x_i = 0 .\]

A wedge monomial \(\mathrm{d} x_{i_1} \wedge \dots \wedge \mathrm{d} x_{i_k}\) therefore carries a sign: the parity of the permutation that orders its index set. fdg encodes a wedge monomial as a CovectorBasis: a bit mask of the component indices plus a sign bit that stores this parity. The wedge product merges the two bit masks and flips the sign once for every index of the second factor that must be moved past a larger index of the first factor; if the masks overlap the product is zero. This is exactly the permutation parity of the merged index set. In the Python API the wedge product of two CovectorBasis objects is written with the XOR operator ^.

The Hodge Star#

The Hodge star maps a \(k\)-form to an \((N - k)\)-form. fdg uses the Euclidean Hodge star with respect to the ordered basis \((\mathrm{d} x_1, \dots, \mathrm{d} x_N)\) and the volume form \(\mathrm{d} x_1 \wedge \dots \wedge \mathrm{d} x_N\):

\[\star\left(\mathrm{d} x_{i_1} \wedge \dots \wedge \mathrm{d} x_{i_k}\right) = \operatorname{sgn}(\sigma)\, \mathrm{d} x_{j_1} \wedge \dots \wedge \mathrm{d} x_{j_{N-k}},\]

where \(\{j_1, \dots, j_{N-k}\}\) is the complement of \(\{i_1, \dots, i_k\}\) in ascending order and \(\operatorname{sgn}(\sigma)\) is the parity of the permutation that sorts \((i_1, \dots, i_k, j_1, \dots, j_{N-k})\) into \((1, \dots, N)\). No metric factors or extra powers of \((-1)^{k(N-k)}\) are included. In the Python API the Hodge star of a CovectorBasis is written with the inversion operator ~. The library uses the Hodge star primarily to classify and order components, not to build the inner product.

The Exterior Derivative#

The exterior derivative of a \(k\)-form is the \((k + 1)\)-form

\[\mathrm{d}\omega = \sum_{i_1 < \dots < i_k} \sum_{j = 1}^{N} \frac{\partial \omega_{i_1 \dots i_k}}{\partial x_j}\, \mathrm{d} x_j \wedge \mathrm{d} x_{i_1} \wedge \dots \wedge \mathrm{d} x_{i_k} .\]

Moving \(\mathrm{d} x_j\) into its sorted position contributes the sign \((-1)^m\), where \(m\) is the number of indices \(i_l < j\). In fdg the exterior derivative is applied to the degrees of freedom: for each component of the input \(k\)-form and each axis \(j\) not in its index set, the one-dimensional derivative operator of the basis along that axis is applied and the result is placed into the component of the output \((k + 1)\)-form whose index set contains the input set plus \(j\), with the sign \((-1)^m\). The resulting matrix is the incidence matrix \(\mathbb{E}^{(k+1,k)}\) of Exterior Derivative.

The Interior Product#

The interior product of a \(k\)-form with a vector field \(X = \sum_j X^j \, \partial / \partial x_j\) is the \((k - 1)\)-form

\[(\iota_X \omega)_{i_1 \dots i_{k-1}} = \sum_{j = 1}^{k} (-1)^{j - 1} X^{i_j}\, \omega_{i_1 \dots i_{j-1} i_j i_j \dots i_{k-1}},\]

i.e. each index of the form is contracted with the vector field in turn, with the sign of the permutation that removes it. It is the algebraic dual of the wedge product:

\[\iota_X(\alpha \wedge \beta) = (\iota_X \alpha) \wedge \beta + (-1)^{\deg \alpha}\, \alpha \wedge (\iota_X \beta) .\]

The library computes the mass matrix of the inner product of a \((k - 1)\)-form test with \(\iota_X \omega\) (compute_kform_interior_product_matrix()), see Interior Product.

Pullback and the Basis Transform#

Let \(F : \vec{\xi} \mapsto \vec{x}\) be a space mapping with Jacobian

\[\begin{split}J_{mi} = \frac{\partial x_m}{\partial \xi_i}, \qquad J = \begin{bmatrix} \dfrac{\partial x_1}{\partial \xi_1} & \cdots & \dfrac{\partial x_1}{\partial \xi_N} \\[2mm] \vdots & \ddots & \vdots \\[2mm] \dfrac{\partial x_M}{\partial \xi_1} & \cdots & \dfrac{\partial x_M}{\partial \xi_N} \end{bmatrix} \in \mathbb{R}^{M \times N}.\end{split}\]

A \(1\)-form on the physical domain pulls back component-wise with the transpose of the inverse Jacobian,

\[F^*(\mathrm{d} x_m) = \sum_{i = 1}^{N} \frac{\partial \xi_i}{\partial x_m}\, \mathrm{d} \xi_i,\]

and a general \(k\)-form pulls back with the \(k\)-th exterior power of this map, i.e. the wedge products of the rows are expanded and collected. fdg evaluates this expansion explicitly: the basis transform \(\mathbf{T}^{(k)}\) returned by SpaceMap.basis_transform() is a three-index array \(T^{(k)}_{ab}(\vec{\xi})\) that gives the coefficient with which the reference component \(a\) (an ascending \(k\)-subset of the reference axes) contributes to the physical component \(b\) (an ascending \(k\)-subset of the physical axes) at each integration point,

\[T^{(k)}_{ab} = \sum_{\sigma \in S_k} \operatorname{sgn}(\sigma) \prod_{l = 1}^{k} \frac{\partial \xi_{i_l}}{\partial x_{j_{\sigma(l)}}},\]

where \(a = \{i_1, \dots, i_k\}\), \(b = \{j_1, \dots, j_k\}\) and \(\partial \xi_i / \partial x_j\) are the entries of the (pseudo-) inverse of \(J\). The special cases are \(T^{(1)}_{ab} = \partial \xi_a / \partial x_b\) and, for a square map, \(T^{(N)} = 1/\det J\). See Transforming k-forms for how the components are transformed.

Inner Products#

All inner products in fdg are taken on the physical domain with the Euclidean metric: for two \(k\)-forms with physical components \(\omega_m\) and \(\eta_m\),

\[(\omega, \eta) = \int_{F([-1,1]^N)} \sum_{m} \omega_m\, \eta_m\, \mathrm{d}V, \qquad \mathrm{d}V = |\det J|\, \mathrm{d}\xi_1 \cdots \mathrm{d}\xi_N .\]

Because the Jacobian determinant is stored as the product of the diagonal of the QR factor \(R\), which is non-negative, fdg effectively always integrates with the unsigned volume element \(|\det J|\). For the \(0\)-form mass matrix this gives the weight \(|\det J|\); for the \(N\)-form mass matrix the physical components carry a factor \(1/\det J\), so the combined weight is \(|\det J|^{-1}\); for intermediate orders the basis transform \(\mathbf{T}^{(k)}\) supplies the metric contraction. The details are in Inner Product Mass Matrix. With the Euclidean metric, lowering the index of a \(1\)-form (or of a \(k\)-form) is trivial: the physical components are used directly as the components of the corresponding tangent multivector, which is why the contravariant transform of Transforming k-forms is the plain Jacobian.

Degrees of Freedom#

A function in a tensor-product space is represented by its degrees of freedom (DoFs), one per basis function. For a basis \(\left\{b^k_1, \dots, b^k_{n_k}\right\}\) in each dimension \(k\), the DoF \(c_{i_1 \dots i_N}\) multiplies the basis function

\[\psi_{i_1 \dots i_N}(\vec{\xi}) = \prod_{k = 1}^{N} b^k_{i_k}(\xi_k),\]

so the function is

\[f(\vec{\xi}) = \sum_{i_1 = 1}^{n_1} \cdots \sum_{i_N = 1}^{n_N} c_{i_1 \dots i_N}\, \psi_{i_1 \dots i_N}(\vec{\xi}) .\]

The one-dimensional bases are described in Basis Functions. Derivatives act on the DoFs through the one-dimensional incidence operators of Exterior Derivative.

Interelement Continuity#

A conforming \(k\)-form space ties the per-element spaces together through their tangential traces on shared boundary objects. This section defines the constraint system built by Mesh.compute_kform_continuity_constraints(); the formulas are the ones the C core evaluates.

Let \(S\) be a boundary object of dimension \(N_s\) — a vertex, edge or face — shared by \(m \geq 2\) elements. The pullback of a \(k\)-form onto \(S\) is a \(k\)-form on \(S\) and exists only when \(k \leq N_s\): a component whose wedge axes are not a subset of the object’s axes has a vanishing tangential trace and is never constrained on that object.

Common boundary space. For each incident element the trace space of one component on \(S\) is a tensor-product space whose order along each object axis comes from that element’s basis. fdg links every trace to the lowest order occurring among the incident elements, expanded in the hierarchical Legendre basis: an element boundary cannot be constrained to a higher-order boundary solution, so the lowest common order is the strongest link that never overconstrains. When all incident elements share the same order the moment map is injective on the trace space and the constraints enforce pointwise continuity; when orders differ the higher-order trace is only constrained through its moments against the lower-order test basis, i.e. continuity holds in the \(L^2\) sense on \(S\).

Elimination. Introduce shared boundary DoFs \(u_b\) on the common space of \(S\) and write, for each incident element \(i\),

\[C_b\, u_b - C_i\, u_i = 0,\]

where \(C_b\) and \(C_i\) pair the common test basis with the boundary solution and with the trace of element \(i\). The block \(C_b\, u_b\) is common to all \(m\) equations, so \(u_b\) eliminates and \(m - 1\) independent blocks remain: every non-anchor element is linked to the anchor (the incident element with the lowest identifier) through rows carrying \(-1\) on its own trace coefficients and \(+1\) on the anchor’s. The number of constraint rows on an object is therefore \((m - 1)\, \dim V_S\), with \(V_S\) the own block defined below, and is zero on objects incident to a single element.

Own block. Constraints are emitted only for trace content that the object’s own subobject constraints do not already pin. Along each axis of the object, an active (wedged) axis contributes all of its modes and an inactive axis contributes only its interior modes: the two endpoint functionals along an inactive axis are owned by the lower-dimensional subobjects, whose constraints already tie them. At the lowest order this reproduces the Whitney allocation of DoFs — a \(k\)-form at order \(p = 1\) carries DoFs only on objects of dimension exactly \(k\) — so an object with \(N_s > k\) has an empty own block and needs no constraints of its own: scalar traces agree on shared vertices alone, \(1\)-form traces on shared edges alone, while an object with \(N_s = k\) keeps exactly one mode per component (the \(2\)-form face flux, the \(1\)-form edge value). Higher orders grow the own block by the usual bubble counting: \(p - 1\) edge bubbles for a scalar edge, \(p (p - 1)\) face modes per \(1\)-form component, \((p - 1)^2\) face bubbles for a scalar face. Rows are keyed and ordered by object, then component, then test mode.
