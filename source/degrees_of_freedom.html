Degrees of Freedom#

With a defined function space using FunctionSpace, it is possible to now define a function using a finite number of degrees of freedom (DoF). To help with that, the DegreesOfFreedom is provided. A new DegreesOfFreedom object is created by specifying the FunctionSpace and optionally values of the corresponding DoFs.

This type can be used to reconstruct the values of the function or its gradients, though they are never cached. The only exceptions are the partially cached methods DegreesOfFreedom.reconstruct_at_integration_points() and DegreesOfFreedom.reconstruct_derivative_at_integration_points(), which make use of BasisRegistry and IntegrationRegistry to cache values of basis functions at integration points. Boundary projections at the reference endpoints additionally use the basis registry’s integration-independent endpoint cache.

Reconstruction#

For a tensor-product basis \(\psi_{i_1 \dots i_N}(\vec{\xi}) = \prod_k b^k_{i_k}(\xi_k)\) (see Basis Functions) the value of the function with degrees of freedom \(c_{i_1 \dots i_N}\) at a point \(\vec{\xi}\) is

\[f(\vec{\xi}) = \sum_{i_1, \dots, i_N} c_{i_1 \dots i_N} \prod_{k = 1}^{N} b^k_{i_k}(\xi_k) .\]

Evaluating the one-dimensional basis values (and, for the gradient, the derivatives) at the nodes of an integration space and contracting with the DoFs gives the reconstructed values at all integration points at once; this is what the two cached methods do. Because the one-dimensional bases are polynomial of degree \(o_k\), the reconstructed function is a polynomial of degree \(o_k\) in each reference coordinate, and a derivative along dimension \(k\) lowers the achievable order in that dimension by one.

Derivatives and projections#

  • DegreesOfFreedom.derivative() applies the one-dimensional incidence operator along the given reference dimension (see Exterior Derivative) to the DoFs, producing the DoFs of the partial derivative \(\partial f / \partial \xi_k\) in the space whose order is lowered by one in that dimension.

  • DegreesOfFreedom.plane_projection() evaluates the basis functions of dimension \(k\) at the coordinate \(x\), i.e. it restricts the function to the plane \(\xi_k = x\) and returns the DoFs of the restriction on that plane. At \(x = -1\) or \(x = +1\), the endpoint basis values are retrieved from the integration-independent BasisRegistry cache. This is the operation behind SpaceMap.boundary().

  • DegreesOfFreedom.reverse_orientation() maps the reference coordinate \(\xi_k \in [-1, +1]\) to \(-\xi_k\), i.e. it reverses the orientation of the element along dimension \(k\). The DoFs are relabeled so that the represented function is unchanged: for nodal (Lagrange, Bernstein) bases the nodal values are reversed, for the Legendre basis the coefficients of odd order are negated, since \(P_k(-\xi) = (-1)^k P_k(\xi)\).

  • DegreesOfFreedom.lagrange_projection() re-expresses the function in a Lagrange basis of the given (or the smallest sufficient) orders by interpolation of nodal values, which is used when the function must be sampled at its nodal points.
