Polynomials#

Evaluation and manipulation of the polynomial families used by the basis functions: Bernstein, Legendre and Lagrange polynomials.

All polynomials live on the reference interval \([-1, +1]\). The Legendre polynomials \(P_k\) satisfy \(P_0 = 1\), \(P_1 = x\) and Bonnet’s recurrence, and are not normalized. The Bernstein polynomials of degree \(n\) are \(B^n_k(t) = \binom{n}{k} t^k (1 - t)^{n-k}\) with \(t = (x + 1)/2 \in [0, 1]\). The Lagrange polynomials are the cardinal functions of a nodal set. The definitions, recurrences and derivative identities are given in Basis Functions; the quadrature nodes that double as Lagrange nodes are described in Integration.

static void bernstein_from_power_series(unsigned int n, double coeffs[static n])#

Convert a polynomial from power series form to Bernstein form in place.

On input, coeffs holds the coefficients of a polynomial in the power basis, with the coefficient of x^k at index k. On return, the same array holds the coefficients of the Bernstein basis B_k^n for the same polynomial. The degree n - 1 polynomial is represented with n coefficients in both forms.

Parameters:

  • n – Number of coefficients.

  • coeffs – Array of n doubles; on input the power series coefficients, on output the Bernstein coefficients.

void bernstein_interpolation_vector(double t, unsigned int n, double out[restrict n + 1])#

Compute the values of all Bernstein polynomials of degree n at a point.

Computes out[k] = B_k^n(t) for k = 0..n, where B_k^n(t) = C(n, k) t^k (1-t)^(n-k).

Parameters:

  • t – Point at which the polynomials are evaluated, in the range [0, 1].

  • n – Degree of the Bernstein polynomials; n + 1 values are written.

  • out – Array of n + 1 doubles which receives the polynomial values.

static void bernstein_interpolation_value_derivative_matrix(unsigned int n_in, const double t[static restrict n_in], unsigned int n, double out_value[restrict (n + 1) * n_in], double out_derivative[restrict (n + 1) * n_in])#

Compute the values and first derivatives of Bernstein polynomials at several points.

For each point t[i] (given on [-1, 1] and internally mapped to [0, 1]), the values and first derivatives of the n + 1 Bernstein polynomials of degree n are computed. The layout is basis-major with a stride of n_in: the value of basis k at point i is stored at out_value[k * n_in + i], and likewise for the derivatives.

Parameters:

  • n_in – Number of points.

  • t – Array of n_in points in [-1, 1] at which to evaluate.

  • n – Degree of the Bernstein polynomials.

  • out_value – Array of (n + 1) * n_in doubles which receives the polynomial values.

  • out_derivative – Array of (n + 1) * n_in doubles which receives the first derivatives.

void legendre_eval_bonnet_two(unsigned int n, double x, double out[2])#

Evaluate the two highest Legendre polynomials up to degree n.

Computes out[0] = P_{n-1}(x) and out[1] = P_n(x) using Bonnet’s recurrence. Intended for computing the derivative of P_n, which satisfies (x^2 - 1) P’_n(x) = n (P_{n-1}(x) - x P_n(x)).

Parameters:

  • n – Degree of the highest polynomial; must be at least 2.

  • x – Point at which the polynomials are evaluated.

  • out – Array of 2 doubles which receives P_{n-1}(x) and P_n(x).

void legendre_eval_bonnet(unsigned int n, double x, unsigned int m, double out[m])#

Evaluate the highest Legendre polynomials up to degree n.

Computes out[k] = P_{n - m + 1 + k}(x) for k = 0..m - 1, i.e. the highest m Legendre polynomials of degrees n - m + 1 through n.

Parameters:

  • n – Degree of the highest polynomial.

  • x – Point at which the polynomials are evaluated.

  • m – Number of polynomials to evaluate; must be at least 1 and at most n, with n < 2 * m.

  • out – Array of m doubles which receives the polynomial values.

void legendre_eval_bonnet_all(unsigned int n, double x, double out[n + 1])#

Evaluate all Legendre polynomials up to degree n.

Computes out[k] = P_k(x) for k = 0..n using Bonnet’s recurrence.

Parameters:

  • n – Degree of the highest polynomial.

  • x – Point at which the polynomials are evaluated.

  • out – Array of n + 1 doubles which receives the polynomial values.

void legendre_eval_bonnet_all_stride(unsigned int n, double x, unsigned int stride, unsigned int offset, double out[(n + 1) * stride])#

Evaluate all Legendre polynomials up to degree n with a strided layout.

Computes out[k * stride + offset] = P_k(x) for k = 0..n. This allows writing the values of several points into the same array with one stride.

Parameters:

  • n – Degree of the highest polynomial.

  • x – Point at which the polynomials are evaluated.

  • stride – Distance in doubles between successive polynomial values.

  • offset – Index of the first written element within the array.

  • out – Array of at least (n + 1) * stride doubles, of which the elements offset + k * stride are written.

static void lagrange_polynomial_denominators(unsigned int n, const double nodes[static restrict n], double denominators[restrict n])#

Compute common denominators of Lagrange polynomials.

Computes denominators[i] = prod_{j != i} (nodes[i] - nodes[j]), the product over all nodes except nodes[i] of the difference between nodes[i] and the other nodes. This is the denominator of the Lagrange basis polynomial L_i evaluated at nodes[i].

Parameters:

  • n – Number of nodes.

  • nodes – Array with nodes where the Lagrange polynomial is zero. The nodes must be pairwise distinct; asserted.

  • denominators – Array which receives the denominators.

static void lagrange_polynomial_coefficients(unsigned int n, unsigned int j, const double nodes[static restrict n], double coefficients[restrict n])#

Compute values of Lagrange polynomial coefficients without dividing by the common denominator.

Parameters:

  • n – Number of nodes.

  • j – Index of the Lagrange polynomial. At that node its value will be non-zero.

  • nodes – Array with nodes where the Lagrange polynomial is zero.

  • coefficients – Array which receives the coefficients. The term’s index corresponds to it’s power of x.

static void lagrange_polynomial_values(unsigned int n_pos, const double p_pos[static n_pos], unsigned int n_roots, const double p_roots[static n_roots], double values[restrict n_roots * n_pos], double work[restrict n_roots])#

Compute values of Lagrange polynomials with given nodes at specified locations. The interpolation can be computed for any function on the same mesh by taking the inner product of the weight matrix with the function values.

The result is written row-major: the value of basis polynomial j at position k is stored at values[k * n_roots + j].

Parameters:

  • n_pos – Number of points where polynomials should be evaluated.

  • p_pos – Points where the Lagrange polynomials should be evaluated at.

  • n_roots – Number or roots of Lagrange polynomials, which is also the order of the polynomials.

  • p_roots – Roots of the lagrange polynomials.

  • values – Array which receives the values of Lagrange polynomials.

  • work – Array used to store intermediate results.

static void lagrange_polynomial_values_2(unsigned int n_pos, const double p_pos[static n_pos], unsigned int n_roots, const double p_roots[static n_roots], double values[restrict n_roots * n_pos])#

Compute values of Lagrange polynomials without a work array.

Equivalent to lagrange_polynomial_values, but the denominators are stored in the last row of the output buffer instead of a separate work array. The output layout is identical.

The arguments are preconditions, not values to validate: a point count of zero aborts through CUTL_ASSERT, because it would wrap the offset of the row reserved for the denominators.

Parameters:

  • n_pos – Number of points where polynomials should be evaluated. Must be at least 1.

  • p_pos – Points where the Lagrange polynomials should be evaluated at.

  • n_roots – Number or roots of Lagrange polynomials, which is also the order of the polynomials.

  • p_roots – Roots of the lagrange polynomials.

  • values – Array which receives the values of Lagrange polynomials.

static void lagrange_polynomial_values_transposed(unsigned int n_in, const double pos[static n_in], unsigned int n_nodes, const double x[static n_nodes], double weights[restrict n_nodes * n_in], double work[restrict n_nodes])#

Compute values of Lagrange polynomials with a transposed layout.

Same as lagrange_polynomial_values, but the result is written column-major: the value of basis polynomial j at position k is stored at weights[k + j * n_in].

Parameters:

  • n_in – Number of points where polynomials should be evaluated.

  • pos – Points where the Lagrange polynomials should be evaluated at.

  • n_nodes – Number or roots of Lagrange polynomials, which is also the order of the polynomials.

  • x – Roots of the lagrange polynomials.

  • weights – Array which receives the values of Lagrange polynomials.

  • work – Array used to store intermediate results.

static void lagrange_polynomial_values_transposed_2(unsigned int n_pos, const double p_pos[static n_pos], unsigned int n_roots, const double p_roots[static n_roots], double values[restrict n_roots * n_pos])#

Compute values of Lagrange polynomials with a transposed layout and no work array.

Equivalent to lagrange_polynomial_values_transposed, but the denominators are stored in the last element of each row of the output buffer instead of a separate work array. The output layout is identical.

Parameters:

  • n_roots – Number or roots of Lagrange polynomials, which is also the order of the polynomials.

  • p_roots – Roots of the lagrange polynomials.

  • values – Array which receives the values of Lagrange polynomials.

static void lagrange_polynomial_second_derivative(unsigned int n_in, const double pos[static n_in], unsigned int n_nodes, const double x[static n_nodes], double weights[restrict n_nodes * n_in], double work1[restrict n_nodes], double work2[restrict n_nodes])#

Compute second derivative of Lagrange polynomials with given nodes at specified locations. The interpolation can be computed for any function on the same mesh by taking the inner product of the weight matrix with the function values.

The result is written row-major: the second derivative of basis polynomial j at position k is stored at weights[k * n_nodes + j].

Parameters:

  • n_in – Number of points where the interpolation will be needed.

  • pos – Array of nodes where interpolation will be computed

  • n_nodes – Number of nodes where the function is known.

  • x – Array of x-values of nodes where the function is known which must be monotonically increasing.

  • weights – Array which receives the weights for the interpolation.

  • work1 – Array used to store intermediate results (cache for the denominators).

  • work2 – Array used to store intermediate results (cache for the differences).
