Basis Functions#

Besides Integration, another basic building block of dealing with finite differential forms is basis functions. These determine values of the degrees of freedom actually mean. For a demonstration of what types of basis are available, see Basis Sets Visualization.

One-dimensional bases#

All bases are sets of \(n = o + 1\) polynomial functions of degree \(o\) on the reference interval \([-1, +1]\), one per degree of freedom (BasisType):

Legendre ("legendre"). The basis functions are the Legendre polynomials \(\phi_k = P_k\), \(k = 0, \dots, o\), defined by \(P_0 = 1\), \(P_1 = x\) and Bonnet’s recurrence

\[(k + 1)\, P_{k + 1}(x) = (2k + 1)\, x\, P_k(x) - k\, P_{k - 1}(x).\]

They are not normalized. The degrees of freedom are the coefficients of the expansion \(f = \sum_k c_k P_k\). The derivatives satisfy the recurrence \(P'_k = k\, P_{k-1} + x\, P'_{k-1}\) and the identity

\[P'_n = \sum_{m = 0}^{\lfloor (n - 1) / 2 \rfloor} (2(n - 2m) - 1)\, P_{n - 2m - 1},\]

which is how the derivative degrees of freedom are computed.

Bernstein ("bernstein"). The Bernstein polynomials of degree \(o\),

\[B^n_k(t) = \binom{n}{k}\, t^k (1 - t)^{n - k}, \qquad t = \frac{x + 1}{2} \in [0, 1], \qquad k = 0, \dots, n,\]

with \(n = o\). Their derivatives satisfy

\[\frac{\mathrm{d}}{\mathrm{d}x} B^n_k = \frac{n}{2} \left(B^{n-1}_{k-1} - B^{n-1}_k\right),\]

so the derivative of \(f = \sum_k c_k B^n_k\) has the Bernstein coefficients \(\frac{n}{2}(c_{k+1} - c_k)\) of degree \(n - 1\).

Lagrange ("lagrange-uniform", "lagrange-gauss", "lagrange-gauss-lobatto", "lagrange-chebyshev-gauss"). The cardinal (nodal) functions with respect to a set of \(n = o + 1\) nodes \(x_k\),

\[\begin{split}\phi_k(x) = \prod_{\substack{j = 0 \\ j \ne k}}^{o} \frac{x - x_j}{x_k - x_j}, \qquad \phi_k(x_j) = \delta_{kj}.\end{split}\]

The degrees of freedom are the nodal values \(c_k = f(x_k)\). The node sets are, for \(k = 0, \dots, o\),

Type

Nodes

uniform

\(x_k = \frac{2k}{o} - 1\)

gauss

roots of \(P_{o+1}\) (Gauss-Legendre nodes)

gauss-lobatto

Gauss-Lobatto nodes (includes \(\pm 1\))

chebyshev-gauss

\(x_k = -\cos\!\left(\frac{\pi (2k + 1)}{2(o + 1)}\right)\)

The derivative degrees of freedom are the values of the derivative at the nodes of the degree-\(o - 1\) Lagrange set, obtained from the nodal values by differentiating the cardinal functions.

The values (and first derivatives) of a basis set are tabulated at the nodes of an integration rule and cached by the BasisRegistry; evaluating a basis on demand is also possible through BasisSpecs.values() and BasisSpecs.derivatives().

The same registry also caches the two endpoint value vectors of every one-dimensional basis specification independently of integration rules. These vectors are used by boundary projections at \(-1\) and \(+1\), so repeated boundary extraction does not rebuild the basis or require a Gauss-Lobatto integration rule.

While values of all basis functions can be computed with BasisSpecs, these are not cached. However, values of these bases at integration points are cached using BasisRegistry. Similarly to what was the case with IntegrationRegistry, there is a default one provided that is used if no other is specified.

Function Spaces#

Just as was the case with IntegrationSpecs, when dealing with N-dimensional spaces BasisSpecs objects are bundled together into a FunctionSpace objects. These define the function space based on outer product of basis.

Given basis sets \(b^k = \left\{ b^k_1, \dots, b^k_{n_1} \right\}\) for \(k = 1, \dots, N\), the value of the different basis functions at point with position \(\vec{r} = \begin{bmatrix} x_1 \\ \vdots \\ x_N \end{bmatrix}\) is given by Equation (1). Based on this it is quite clear that the total number of basis functions in this case is \(\prod\limits_{i=1}^N n_i\).

(1)#\[\psi_{i_1, \dots, i_N} (\vec{r}) = \prod\limits_{j = 1}^N b^{j}_{i_1}(x_j)\]
